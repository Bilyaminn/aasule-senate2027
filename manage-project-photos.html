Export downloads a ZIP containing project-photo-overrides.json and an assets/projects/ folder of optimised images. Unzip it into the website’s main folder beside index.html (replace existing files), then redeploy. Use Save backup to keep an editable copy of your photo set.

Important: this is a static website, so the manager cannot upload files directly to your hosting account. It prepares the photo file for you to download and deploy. Draft edits are also kept in this browser until you clear them.
